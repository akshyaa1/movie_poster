# 🎬 Movie Poster Website

A simple and attractive **Movie Poster webpage** created using **HTML and CSS**. This project demonstrates webpage designing, styling, and layout creation using basic front-end technologies.

## 🚀 Features

* Movie poster style user interface
* Attractive dark theme design
* Movie title and tagline display
* Cast information section
* Watch Now button
* Responsive poster layout
* CSS styling with gradients and effects

## 🛠️ Technologies Used

* HTML5
* CSS3
* Visual Studio Code
* Live Server Extension

## 📂 Project Structure

```
movie_poster/
│
├── index.html
├── style.css
└── README.md
```

## ▶️ How to Run the Project

1. Clone this repository:

```
git clone https://github.com/akshyaa1/movie_poster.git
```

2. Open the project folder in Visual Studio Code.

3. Open `index.html` using Live Server.

4. The movie poster webpage will open in your browser.
